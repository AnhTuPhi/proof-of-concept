Real-time Communication Patterns — Java 21 / Spring Boot 3.4

Cùng 1 stream stock price giả lập (tick mỗi 500ms), 4 cách deliver xuống client. Open DevTools → Network để xem từng transport hoạt động khác nhau.

1. Server-Sent Events (SSE)

One-way server → client over HTTP/1.1. Auto-reconnect built-in. Browser native (EventSource). Hợp cho notification, price ticker, progress bar.
GET /sse/prices · text/event-stream
status: disconnected · events: 0

2. WebSocket + STOMP

Full-duplex bi-directional over TCP. Multi-topic subscribe. Hợp cho chat, trading desk, multiplayer. Cần handshake upgrade (vài corp proxy chặn).
WS /ws · SUBSCRIBE /topic/prices
status: disconnected · events: 0

3. Long-polling (fallback)

Client GET, server giữ request bằng DeferredResult đến khi có data hoặc timeout. Cursor-based — không miss event giữa hai vòng.
GET /poll/prices?cursor=N&timeoutMs=25000
status: idle · cursor: 0 · events: 0

4. gRPC streaming

HTTP/2 + protobuf. Bi-directional streaming với type-safe stubs. Hợp service-to-service, mobile. Browser cần grpc-web proxy — demo này dùng REST bridge gọi tới gRPC server local.
gRPC :9090 · PriceStreamService.streamPrices
status: idle · events: 0
Backend: /sse/stats · grpc-java · Generator emits 1-3 price updates every 500ms across 7 Vietnamese symbols (VND, FPT, HPG, VIC, MWG, VHM, MBB).
