    InvariantHow this POC upholds it
    No money without goods, no goods without moneyEvery successful step registers an undo; failure runs undos in reverse (refund → release → cancel).
    Exactly-once effect under at-least-once deliveryChoreography: processed_events(event_id). Orchestration: idempotent activities keyed on orderId/paymentId.
