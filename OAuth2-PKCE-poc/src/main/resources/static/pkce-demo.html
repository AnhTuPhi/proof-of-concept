OAuth2 Authorization Code + PKCE

Public-client flow: SPA generates code_verifier in browser → derives code_challenge via SHA-256 → only the verifier proves possession at token exchange. No client secret needed.

Flow steps

  1. Generate verifier — random 43–128 char URL-safe string, stored in sessionStorage.
  2. Derive challenge — BASE64URL(SHA-256(code_verifier)).
  3. Redirect to /oauth/authorize with the challenge (browser-visible).
  4. Receive code via redirect back here.
  5. POST /oauth/token with code + verifier — server matches verifier to stored challenge, issues JWT.
