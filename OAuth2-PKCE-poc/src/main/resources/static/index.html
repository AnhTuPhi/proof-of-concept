Web / API Patterns — POC

4 patterns every backend dev should know. All running on http://localhost:8080.

1. ETag & 304

Conditional GET. Server returns ETag → client sends If-None-Match → server replies 304 Not Modified with no body. Saves bandwidth.

HTTP caching

2. OAuth2 PKCE

Authorization Code flow with PKCE for public clients (SPA, mobile). Never expose a client secret again.

Authn

3. JWT Refresh Rotation

Short-lived access + rotating refresh tokens. Reuse detection revokes the entire token family on replay.

Token security

4. Content Negotiation

Same URL, different schemas. Vendor media types, version parameter, custom header — three pragmatic styles.

API versioning
