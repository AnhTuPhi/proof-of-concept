Auth & Access POC Suite

Three gnarly auth patterns made small enough to demo end-to-end. Java 21 / Spring Boot 3.4.3.

28 · Account Merge

port 8081

User signed up via Google two years ago, forgot, and just signed up again with email. Merge their data across N tables without hard-deleting either user — both auth methods keep working.

Open demo →

29 · Multi-Device Sessions

port 8082

Phone, laptop, and tablet all logged in. User changes password — every in-flight JWT becomes invalid instantly via token-version bumping. Refresh tokens rotate on every use.

Open demo →

30 · Tiered Rate Limiting

port 8083

Token-bucket limits per tier (Free / Pro / Enterprise). Three independent dimensions — user, IP, endpoint. 429 with Retry-After when any dimension trips.

Open demo →

Running the suite

From D:\Claude\poc-demos, build the parent and start each module in its own terminal: 
mvn -q clean install -DskipTests
mvn -q -pl account-merge-poc       spring-boot:run
mvn -q -pl session-management-poc  spring-boot:run
mvn -q -pl tiered-rate-limit-poc   spring-boot:run
Then open http://localhost:8081/account-merge.html (or the other two). Each module exposes its own static HTML; you can also open this hub file directly via file://.
