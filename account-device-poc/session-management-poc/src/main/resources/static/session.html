Account controls

Changing the password bumps tokenVersion on the user record. Every JWT and refresh token previously issued embedded the old version — so every device drops to "stale token version" on next validation. Each device must reauthenticate.

A pure JWT can't be revoked. The version-check on every validation is what gives us instant logout-everywhere without a per-token blocklist.
